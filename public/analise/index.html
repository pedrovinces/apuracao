Carregando os dados do TSE…

Fontes: boletins de urna dos dois turnos (dados abertos do TSE, arquivos bweb) e logs das urnas do 2º turno (arquivo-urna em resultados.tse.jus.br). Horários convertidos para Brasília. Malha municipal: IBGE.

O voto é secreto: nenhum dado público liga um voto a um horário ou a um eleitor. O log diz quantas pessoas votaram em cada horário; o boletim diz o total de cada candidato na seção. Os scripts que geram estes dados estão em tools/analise/ no repositório, para qualquer pessoa refazer a conta.

Como estes números foram feitos
  • Votos por seção: boletins de urna dos dois turnos publicados pelo TSE em dados abertos (arquivos bweb_1t_UF e bweb_2t_UF), apenas o cargo de Presidente. As seções são comparadas pela chave município + zona + seção.
  • Horários: abertura e encerramento vêm do boletim, na hora local da urna. Como todas as urnas abrem às 8h de Brasília, a diferença de fuso de cada município é a hora local de abertura mais comum ali menos 8. Assim AC (+2 h), AM, MT, MS, RO e RR (+1 h) e Fernando de Noronha (−1 h) são convertidos para Brasília.
  • Votos depois das 17h: contados no log de cada urna (arquivo público do TSE), linha "O voto do eleitor foi computado" com horário depois das 17:00:00 de Brasília. Lemos o log de todas as seções que fecharam depois das 17:15 e de uma amostra aleatória (semente fixa 20261025) das que fecharam entre 17:00 e 17:15; para esse grupo o total é estimado pela média da amostra, com intervalo de 95%.
  • Voto secreto: o log registra que um voto foi computado e a hora, nunca o candidato. O registro digital do voto embaralha os votos sem horário. Por isso nenhum dado diz em quem votaram as pessoas depois das 17h; os cenários do simulador usam hipóteses extremas para mostrar o efeito máximo possível.
  • Cuidados na comparação entre turnos: seções podem ser agregadas de forma diferente em cada turno, mudar de local ou existir em um turno só; elas aparecem marcadas. Percentuais são sobre votos válidos de cada turno.
  • Dados pessoais: os logs trazem dados de mesários (como o título digitado no encerramento); nada disso é guardado ou publicado, só contagens.
